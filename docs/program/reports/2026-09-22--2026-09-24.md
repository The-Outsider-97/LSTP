## Security and reliability findings

Permission handling remains fail-closed by absence: there is no runtime path that can convert requested authority into execution. This is safer than introducing premature aliases or privilege ordering, but it is not an implementation of the permission model.

The largest current safety risk is semantic widening during future carrier conversion. D-011 therefore prohibits case-folding/alias coercion of unsupported modes and requires preservation of scope, forbids, limits, confirmation, review, and logging constraints.

The parser is not yet exposed, so parser resource-exhaustion claims cannot be made. Existing bounded JSON decoding is not evidence that future Lattice parsing is bounded.
